# İnsan — 4. bileşen

Otomasyonun devredemediği iş. Ama otomasyon yine de hakkı kurar: kuyruğu açar,
nöbeti yazar, süreyi takip eder ve **kabul kriteri olmadan iş emrini kapatmaz**.

| Şablon | Ne zaman |
|--------|----------|
| `templates/access_pack.md` | 0. gün erişim paketi — devreye almanın ilk adımı |
| `templates/work_order.md` | Saha iş emri |
| `templates/acceptance.md` | Proje → yönetilen devri; kurulum bununla kapanır |
| `templates/pentest_authorization.md` | Sızma testi yetki mektubu — imzasız test başlamaz |
| `runbooks/dr_failover.md` | Felaket kurtarma; failover'ı kimin ilan edeceği yazılıdır |
